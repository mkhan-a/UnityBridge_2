 UnityBridge

 Overview
UnityBridge is a web-based mutual aid and resource exchange platform that connects individuals within local communities using ZIP code-based matching.

Features
- User account creation and login
- Post requests and offers for help
- Browse and filter by ZIP code
- Accept/fulfill requests
- Rating and review system
- Admin moderation tools

 Tech Stack
- Frontend: (HTML/CSS/JS or React)
- Backend: (Java / Node.js)
- Database: SQL (SQL Server)


Folder Structure
- `/docs` → SRS, WBS, reports
- `/wireframes` → UI designs
- `/src` → application code
- `/tests` → testing documents
- `/assets` → images/icons
